# Internal Testing Checklist

## Core flow
- Sign in and confirm the app opens without a startup error.
- Switch between Overview, Bills, Payoff, Trends, and More.
- Confirm solo mode still works.
- Confirm household mode still works.

## Daily-use flow
- Mark a bill paid.
- Edit a bill from Bills.
- Edit the same bill from Settings and confirm both sides stay in sync.
- Open the progress home and confirm the main numbers match.

## Import flow
- Try Excel/CSV import.
- Try PDF statement import.
- Try image or screenshot import.
- Confirm the detected account fields look reasonable before saving.

## Household flow
- Create or join a household.
- Approve or reject a join request if available.
- Confirm shared updates appear for household members only.

## Launch safety
- Confirm billing shows as coming soon for testers.
- Confirm premium-style features stay available for testers.
- Send one feedback note from the app.
- Copy version and user id from Settings when reporting issues.
